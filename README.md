# About
a Left 4 Dead 2 VScript mod that allows you have free camera anytime you want witch chat commands if you are server host
very useful for scene recording or taking special screenshots for your custom campaigns or something.

# Commands

!freecam: Toggles Free Camera on server host (use same command again to disable it)
!freezebots: Freezes all Survivor bots, very useful for getting screenshots.
!hudtoggle: Disable your health hud, doesn't disables other survivors huds or chat.
!freecamspeed <value>: Change the speed of camera (default is 500)
!timescale <value>: Change the game speed, useful for taking screenshots of quick time events. (only works in singleplayer)
